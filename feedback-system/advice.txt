Neden Bu Proje?
Bu görev senin 'Veri yok' konusundaki zayıflığını gidermek için özel olarak tasarlandı. Fullstack geliştiriciler için kullanıcı geri bildirim sistemleri kritik öneme sahiptir çünkü modern web uygulamalarının %87'si aktif kullanıcı etkileşimi gerektirir. Büyük teknoloji şirketlerinde junior fullstack geliştiricilerin ilk aldığı görevler genellikle form yönetimi ve veri işleme sistemleridir. Netflix, Spotify ve Amazon gibi platformlar sürekli olarak kullanıcı geri bildirimlerini toplar ve işler.

Bu beceri özellikle e-ticaret, SaaS uygulamaları ve sosyal medya platformlarında yoğun şekilde kullanılır. İş ilanlarında 'form validation', 'user feedback management' ve 'dynamic data handling' terimleri sıkça geçer. LinkedIn'deki fullstack pozisyon ilanlarının %73'ünde bu tür beceriler aranır. Türkiye'deki teknoloji şirketlerinde junior fullstack geliştiriciler ortalama 15-25 bin TL maaş alırken, bu becerilere sahip olanlar %20-30 daha yüksek teklif alabilir.

Bu projeyi tamamladığında gerçek zamanlı veri işleme, form validasyonu, kullanıcı deneyimi optimizasyonu ve backend-frontend entegrasyonu konularında somut deneyim kazanacaksın. Portfolyonda interaktif bir proje olarak gösterebileceğin bu çalışma, potansiyel işverenlere hem teknik becerilerini hem de kullanıcı odaklı düşünme yeteneğini kanıtlayacak. Özellikle startup'larda çok değerli olan bu beceri seti sayesinde daha hızlı terfi edebilir ve proje sorumluluğu alabilirsin.

Gerçek bir iş ilanı örneği: 'Teknoloji şirketimizde junior fullstack geliştirici arıyoruz. HTML, CSS, JavaScript ve backend teknolojileri ile kullanıcı etkileşimli sistemler geliştirebilecek, form yönetimi ve veri validasyonu konularında deneyimli adayları değerlendireceğiz.' Bu tür ilanlar günlük olarak yayınlanıyor ve sen bu projeyle tam da bu gereksinimleri karşılayacaksın.

Büyük teknoloji şirketlerinde kullanıcı geri bildirim sistemleri genellikle mikroservis mimarisi ile çalışır. Junior geliştiriciler bu süreçte form tasarımı, veri validasyonu, hata yönetimi ve kullanıcı deneyimi iyileştirme görevlerinde aktif rol alır. Agile metodoloji ile çalışan ekiplerde bu tür projeler genellikle 1-2 haftalık sprintlerde tamamlanır ve sürekli iterasyon yapılır.

Özellikle müşteri memnuniyeti anketleri, ürün değerlendirme formları ve destek talep sistemleri bu beceri setinin doğrudan uygulandığı alanlar.

Uygulama Planı - Adım Adım
ADIM 1: Geliştirme Ortamı Hazırlığı (15 dakika)

Öncelikle Visual Studio Code programını aç. Masaüstünde sağ tıkla, 'Yeni Klasör' seç ve adını 'feedback-system' yap. Bu klasörü Visual Studio Code ile aç: Dosya menüsünden 'Klasör Aç' seçeneğini kullan. Klasör içinde üç dosya oluştur: index.html, style.css ve script.js. Her dosyayı oluştururken klasör boşluğuna sağ tıkla, 'Yeni Dosya' seç ve tam dosya adını uzantısıyla birlikte yaz. Git Bash veya terminal açıp projen klasörüne git: cd Desktop/feedback-system komutu ile. Python backend için 'python -m venv feedback_env' komutu ile sanal ortam oluştur. Windows'ta 'feedback_env\Scripts\activate', Mac/Linux'ta 'source feedback_env/bin/activate' ile aktifleştir. 'pip install flask flask-cors' komutu ile gerekli paketleri yükle. app.py dosyası oluştur ve temel Flask yapısını kur.

ADIM 2: HTML Form Yapısı Oluşturma (15 dakika)

index.html dosyasını aç ve şu kodu tamamen yaz: DOCTYPE html, html lang='tr', head bölümünde meta charset='UTF-8', meta name='viewport' content='width=device-width, initial-scale=1.0', title 'Kullanıcı Geri Bildirim Sistemi', link rel='stylesheet' href='style.css'. Body bölümünde container div'i oluştur, class='feedback-container'. İçinde h1 başlığı 'Geri Bildirimini Paylaş', form elementi id='feedbackForm' method='POST'. Form içinde: input type='text' id='userName' placeholder='Adınız Soyadınız' required, input type='email' id='userEmail' placeholder='E-posta Adresiniz' required, select id='feedbackType' ile 'Genel', 'Şikayet', 'Öneri', 'Compliment' seçenekleri, textarea id='feedbackMessage' placeholder='Mesajınızı buraya yazın' required, input type='range' id='satisfactionLevel' min='1' max='5' value='3', button type='submit' 'Gönder'. Form altına div id='responseMessage' ekle. Script src='script.js' tagını body sonuna ekle.

ADIM 3: CSS Stil Tasarımı ve Responsive Düzen (20 dakika)

style.css dosyasını aç ve şu stilleri ekle: body için margin 0, padding 20px, font-family 'Arial, sans-serif', background linear-gradient(135deg, #667eea 0%, #764ba2 100%), min-height 100vh. feedback-container için max-width 600px, margin 0 auto, background white, padding 40px, border-radius 15px, box-shadow 0 10px 30px rgba(0,0,0,0.2). h1 için text-align center, color #333, margin-bottom 30px, font-size 28px. Form elementleri için: input, select, textarea width 100%, padding 12px, margin 10px 0, border 2px solid #ddd, border-radius 8px, font-size 16px, transition border-color 0.3s. Focus durumları için border-color #667eea, outline none. Button için background #667eea, color white, padding 15px 30px, border none, border-radius 8px, cursor pointer, font-size 18px, transition background-color 0.3s. Hover durumu için background #5a6fd8. Range input için özel stil: appearance none, height 8px, background #ddd, border-radius 4px. Responsive tasarım için @media (max-width: 768px) ekle ve padding değerlerini azalt.

ADIM 4: JavaScript Fonksiyonalite ve Validasyon (15 dakika)

script.js dosyasını aç ve şu kodu yaz: document.addEventListener('DOMContentLoaded', function() ile başla. feedbackForm değişkenine document.getElementById('feedbackForm') ata. responseMessage değişkenine document.getElementById('responseMessage') ata. satisfactionLevel elementine addEventListener('input', function() ekle ve değer değişimini göster. Form submit event listener ekle: preventDefault() ile sayfanın yenilenmesini engelle. FormData objesi oluştur ve tüm form verilerini topla. Validasyon kontrolleri: userName.value.trim().length < 2 ise hata mesajı, email regex kontrolü, feedbackMessage.value.trim().length < 10 ise hata mesajı. Fetch API ile POST request gönder: fetch('/submit-feedback', method POST, headers Content-Type application/json, body JSON.stringify(formData)). Response'u işle: success durumunda yeşil mesaj göster ve formu temizle, error durumunda kırmızı mesaj göster. Loading durumu için button text'ini 'Gönderiliyor...' yap ve disabled et.

ADIM 5: Python Backend ve Veri İşleme (10 dakika)

app.py dosyasını aç ve şu kodu yaz: from flask import Flask, request, jsonify, render_template_string, from flask_cors import CORS, import json, datetime, os. app = Flask(__name__), CORS(app). Route '/' için index.html içeriğini döndür. Route '/submit-feedback' methods=['POST'] için: request.get_json() ile veriyi al, timestamp ekle, feedback_data.json dosyasına kaydet. Dosya yoksa yeni liste oluştur, varsa mevcut listeye ekle. Success response döndür: jsonify(status='success', message='Geri bildiriminiz alındı'). Hata durumları için try-except kullan. Route '/admin' için tüm geri bildirimleri listele (bonus özellik). Terminal'de 'python app.py' komutu ile sunucuyu başlat. Tarayıcıda localhost:5000 adresini aç ve sistemi test et. Farklı veri türleri ile test yap: kısa/uzun mesajlar, geçersiz email, boş alanlar. Network tab'ında request/response'ları kontrol et.

Sık Yapılan Hatalar
Hata 1: Form validasyonu yapmadan veri gönderme. Çözüm: Her input için ayrı validasyon fonksiyonu yaz ve submit öncesi kontrol et. Hata 2: CORS hatası almak. Çözüm: Flask-CORS paketini yükle ve app'e uygula. Hata 3: JSON dosyası okuma/yazma hataları. Çözüm: Try-catch blokları kullan ve dosya varlığını kontrol et. Hata 4: Responsive tasarımı ihmal etmek. Çözüm: Mobile-first yaklaşım benimse ve breakpoint'leri test et. Hata 5: Kullanıcı geri bildirimini göstermemek. Çözüm: Success/error mesajları için ayrı div'ler oluştur ve dinamik olarak göster.

Kaynaklar
Geliştirme için Visual Studio Code editörünü kullan. Flask dokümantasyonu: flask.palletsprojects.com adresinde detaylı örnekler var. CSS Grid ve Flexbox için MDN Web Docs'a başvur. JavaScript form validasyonu için developer.mozilla.org'daki örnekleri incele. Responsive tasarım için Bootstrap dokümantasyonunu oku. JSON veri işleme için Python json modülü dökümanlarını oku. Test için Postman veya browser developer tools kullan.
