# 🚀 Sparkgen Kariyer Yolculuğum

Bu depo; Sparkgen Akademi eğitimi boyunca ve bağımsız olarak geliştirdiğim, siber güvenlik vizyonuyla harmanlanmış Full-Stack (Frontend & Backend) yazılım projelerimi ve analitik çalışmalarımı içermektedir.

💡 "Söz uçar, yazı kalır" mottosuyla; bu süreçte öğrendiğim teknolojileri, karşılaştığım debug süreçlerini ve siber güvenlik odaklı yaklaşımlarımı hem topluluğa faydalı olmak hem de kalıcı bir dijital imza bırakmak adına projelendirip dökümante ediyorum.

🛠️ Teknolojik Cephanelik (Tech Stack)
Backend & Veri Analitiği: Python 3.12, Flask, Flask-SQLAlchemy (ORM), Flask-CORS, SQLite, Pandas, Matplotlib, Seaborn

Frontend Web Geliştirme: HTML5, CSS3 (Modern UI & Animasyonlar), Vanilla JavaScript (ES6+, Fetch API, Asynchronous JS)

Süreç & Güvenlik Standartları: RESTful API Design, Girdi Validasyonu, XSS Koruması, CORS Yönetimi, Git & Açık Kaynak Proje Standartları

## 📁 Projelerim

### 1. 📊 Veri Analizi Dashboard (Adım 3-4-5)
* **Açıklama:** Python, Pandas ve Matplotlib kullanılarak hazırlanan satış analiz dashboard'u.
* **Klasör:** `/veri_dashboard`
* **Öne Çıkanlar:** CSV veri işleme, Zaman serisi analizi, Pasta ve Bar grafikleri.

### 2. 🌤️ Canlı Hava Durumu Uygulaması
* **Açıklama:** Üçüncü parti OpenWeatherMap API'si üzerinden küresel hava durumu verilerini asenkron tüketen dinamik web uygulaması.
* **Klasör:** `/hava durumu uygulaması`
* **Öne Çıkanlar:** Async/Await mimarisi, Fetch API, Dinamik DOM manipülasyonu ve try-catch hata yönetimi.

### 3. 🚀 Mini Blog İçerik Yönetim Sistemi (Blog-CMS)
* **Açıklama:** Full-stack mimariyi ve CRUD operasyonlarını anlamak amacıyla geliştirilmiş hafif İçerik Yönetim Sistemi.
* **Klasör:** `/blog-cms`
* **Öne Çıkanlar:** Python Flask backend, SQLite veritabanı entegrasyonu ve escapeHTML ile proaktif XSS siber güvenlik koruması.

### 4. 🛒 E-Ticaret API Sistemi
* **Açıklama:** Ürün, sepet ve sipariş yönetim süreçlerinin arka plan lojistiğini otomatize eden RESTful API çalışması.
* **Klasör:** `/e-ticaret_API`
* **Öne Çıkanlar:** HTTP istek yönetimi (GET, POST), JSON veri serileştirme ve endpoint mimarisi.

### 5.🔁 Geri Bildirim Yönetim Sistemi
* **Açıklama:** Kullanıcı dönüşlerini ve sistem loglarını veritabanı üzerinde anlamlı metriklere dönüştüren veri akış hattı.
* **Klasör:** `/geri bildirim sistemi`
* **Öne Çıkanlar:** İlişkisel veri modelleri, kullanıcı girdi analizi ve dinamik veri loglama.

### 6. 🔥 Isı Haritası Uygulaması
* **Açıklama:** Coğrafi veya operasyonel yoğunluk verilerini görselleştirerek anomali tespiti sağlayan frontend/analiz çalışması.
* **Klasör:** `/ısı haritası uygulaması`
* **Öne Çıkanlar:** Matplotlib/Seaborn yoğunluk grafikleri, koordinat eşleme ve görsel veri analitiği.

### 7. 📦 Akıllı Stok Takip Sistemi
* **Açıklama:** Depo, envanter ve kritik stok sınırları için dinamik veri modelleri içeren yönetim paneli.
* **Klasör: ** `/stok-takip-sistemi`
* **Öne Çıkanlar:** Stok durum takibi, kritik eşik uyarı algoritmaları ve veri manipülasyonu.

⚙️ Yerel Çalıştırma Standartları (Global Guide)
Bu depodaki Python tabanlı projelerin kararlı çalışabilmesi için .gitignore standartlarına uygun olarak sanal ortam klasörleri (feedback_env/, weather_env/) repoya dahil edilmemiştir.

İlgili projeleri çalıştırmak için projenin kendi klasörüne girip şu adımları izleyebilirsiniz:

Temiz bir sanal ortam ayağa kaldırın: ``python -m venv env``

Sanal ortamı aktifleştirin (Windows): ``env\Scripts\activate``

Bağımlılıkları yükleyin: ``pip install -r requirements.txt``
