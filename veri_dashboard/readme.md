# 📊 Satış Veri Analizi Dashboard Projesi

Bu klasör, Sparkgen Akademi eğitiminin 3, 4 ve 5. adımlarını kapsayan veri analizi projesini içerir.

## 📝 Proje Amacı
`data.csv` dosyasındaki satış verilerini kullanarak; ürün bazlı toplam satışları, günlük satış trendlerini ve bölgesel satış dağılımlarını görselleştirmek.

## 🛠 Kullanılan Kütüphaneler
- **Pandas:** Veri manipülasyonu ve analizi.
- **Matplotlib:** Statik grafiklerin (Bar, Line, Pie) oluşturulması.
- **Plotly:** İnteraktif grafik deneyimi.

## 📂 Dosya Yapısı
- `main.py`: Tüm analiz ve görselleştirme kodlarının bulunduğu ana dosya.
- `data.csv`: Analiz edilen ham veri seti.
- `requirements.txt`: Gerekli kütüphanelerin listesi.
- `resimler/`: Çıktı olarak alınan grafiklerin ekran görüntüleri.

## 🚀 Çalıştırma
Projeyi kendi bilgisayarınızda çalıştırmak için:
1. `pip install -r requirements.txt`
2. `python main.py`
